WITH YOU PHOTO FRAME

File principale:
- index.html

Cornici:
- images/frames/frame1.svg
- images/frames/frame2.svg
- images/frames/frame3.svg
- images/frames/frame4.svg

Per personalizzare un evento:
1. Crea una grafica verticale 1080x1920 con sfondo trasparente.
2. Lascia libera l'area foto indicativa x=139, y=228, larghezza=802, altezza=1471.
3. Esporta in PNG trasparente.
4. Sostituisci i file frame1.svg ecc. e aggiorna nell'HTML l'estensione da .svg a .png se necessario.

Pubblicazione rapida:
- carica l'intera cartella su GitHub
- importa il repository in Vercel
- nessun backend necessario

Nota:
La fotocamera utilizza input file con capture="user", quindi su smartphone apre normalmente la camera frontale tramite il browser.
